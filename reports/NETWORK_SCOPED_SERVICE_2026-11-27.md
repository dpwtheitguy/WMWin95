## Implemented boundary

`control_panel/network_service.py` defines typed state encode/decode, protected root-owned policy loading, Unix peer credentials, logind active/local/graphical-session verification, profile UUID/interface/type allowlist, strict operation/field validation and bounded request decoding. Production entry requires the immutable guest marker and existing guest guard. No uid, executable, arbitrary path, command, credential, policy or permission supplied in a request can authorize itself.

Only existing-profile IPv4 assignment/address/mask, gateway, DNS/search, DHCP hostname and autoconnect are editable. Existing routes, routing-only search domains, additional addresses, never-default, IPv6 and credentials remain untouched. QA policy additionally requires dummy/w95uat interface identity, autoconnect off, no gateway or global search domain, never-default, routing-only win95lx-uat.invalid and actual NM routing table49995/DNS priority32760/IPv6 disabled.

Before mutation the privileged service rereads authoritative inventory, including active state, rather than trusting a request claiming the connection is inactive. It uses the existing transaction model for changed-field-only writes, activation, authoritative readback and attempted-profile rollback. A durable pre-change journal blocks further updates after interrupted/partial recovery until maintenance verifies the actual state. Fully restored failures and confirmed successes clear the pending journal. The service does not blindly replay a stale journal over external changes.

Commands use direct argv and fixed nmcli path, no prompt or shell. Forward work has a45-second budget with per-command deadlines; rollback has a separate35-second budget and final recovery check10seconds. These are failure ceilings, not measured normal latency. A64-entry idempotency cache prevents duplicate successful request IDs from writing twice. Socket requests are serialized. `ServiceNetworkManager` retains unprivileged reads and forwards only edited profiles, so untouched profiles are excluded from rollback.

`dev/guest_install_network_service.sh` is prepared for review. It requires an already provisioned protected policy and root-owned release, and installs only this fixed service. It has NOT been executed. It grants no general NM polkit action, invokes no user sudo and does not choose a connection to authorize. The existing unregistered Network window now selects the scoped adapter only when the protected root-owned guest service socket exists; otherwise it keeps the current read-only/policy-gated backend. This selector performs no service I/O on the GTK thread. Main app/Control Panel registration has not been changed.

### Next production-policy iteration

The proven dummy policy is a QA capability, not an end-user hardware policy. Extend admission through a reviewed installer/root-owned discovery step that binds approved existing NetworkManager profile UUIDs to actual physical adapter identity/type. The current schema can already represent reviewed non-QA existing ethernet/wireless profiles, but no such profile has been authorized or tested. Hotplug or profile recreation must not silently admit an unrelated UUID through a client request. A future narrow capability query should let the UI distinguish editable and read-only adapters before Apply, with a keyboard-accessible explanation.

Keep the same active-local non-admin session authentication and typed helper, without granting general NM actions or showing sudo/UAC/password elevation. Actual physical-adapter tests need a dedicated expendable interface/profile and independent recovery access; retain the primary developer route unchanged. Before enabling edits to the user's primary link, add measured activation/checkpoint recovery, loss-of-connectivity behavior and explicit rollback acceptance. Wi-Fi credentials/keyring management, hostname, profile creation/removal, WINS/NetBIOS, Samba sharing/workgroup and bindings remain separate feature contracts. Do not label those functions complete merely because this existing-profile transaction is accepted.
